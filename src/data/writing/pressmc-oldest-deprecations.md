## Method

- **Scope:** all 2,139 `@Deprecated` annotations in `paper-api/src/main/java`.
- **Bukkit-origin members** were dated with `git blame -w` in Bukkit's repo, skipping commit `d14119af` ("#1082: Add \"since\" to Deprecation annotations", 2024-11-25), which backfilled every `since` tag. At the old end, the commit dates match the `since` tags exactly.
- **Paper/Spigot patch-era members** were dated by replaying the pre-hard-fork API patch history (Spigot `Bukkit-Patches/`, Paper `Spigot-API-Patches/` and `patches/api/`) and taking the start of the run in which each member's `+ @Deprecated` line appeared and then stayed. This filters out md_5's April Fools' 2014 patch "Deprecate Some Stuff" (Spigot `6023c0a6`), which deprecated about 5,500 members and was reverted the next day.
- **Post-hard-fork members** (from 2024-12-11) were dated with blame in Paper `main`, skipping the bulk rewrite commit "Update a whole lot of deprecated annotations" (`9f004614`).
- **Known caveat:** when a member was moved or re-declared (e.g. `Art` becoming an interface in 2024), blame shows the rewrite date, and the `since` tag is the better guide. None of those fall in this list.
